# .github

Default issue and pull request templates for `diegoavilac` repositories. A repository that ships its own template uses that one instead.

The repository is public on purpose: GitHub applies default templates only from a public `.github` repository. It contains templates and nothing else. Never add secrets, account identifiers or private project details here.

The conventions these templates follow live in `09-AI-Context/AGENT_CONVENTIONS.md` of the Cerebro repository.
